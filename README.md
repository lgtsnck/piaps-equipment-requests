# Учёт и обработка заявок на приобретение оборудования

Учебный проект по дисциплине **«Проектирование и архитектура программных систем» (ПиАПС)**.

Цель проекта — спроектировать информационную систему регистрации, согласования и обработки заявок подразделений на приобретение оборудования, реализовать небольшой программный прототип и проверить его соответствие установленным требованиям.

**Предметная область** — адаптированный вариант № 3 лабораторного практикума «Проектирование информационных систем», связанный с учётом основных средств в отделе материально-технического снабжения (МТС). В проекте рассматривается учёт заявок **на приобретение оборудования**. Четыре лабораторные работы выполняются последовательно в рамках одного проекта.

## Назначение и границы системы

Предусмотрены три роли — **заявитель**, **руководитель МТС** и **специалист МТС**. Основной процесс включает создание заявки, проверку данных, согласование или возврат на уточнение, назначение исполнителя, обработку и закрытие. Также предусмотрена возможность отклонения заявки с указанием причины.

Фактические закупки, платежи, бухгалтерский и складской учёт, а также интеграции с поставщиками и внешними системами в учебный прототип не входят.

## Подготовка окружения

Для первоначальной настройки нужен установленный [uv](https://docs.astral.sh/uv/). Выполнить:

```powershell
git clone https://github.com/lgtsnck/piaps-equipment-requests.git
cd piaps-equipment-requests
uv sync
uv run python --version
uv run python -m tkinter
```

Последняя команда открывает тестовое окно Tkinter. Запуск самого приложения и автоматизированных тестов будет документирован после реализации прототипа. Локальное окружение `.venv/` не включается в репозиторий.
